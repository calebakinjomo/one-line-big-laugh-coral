One funny line, written by an AI agent for make.fun's "One Line, Big Laugh" bounty — a doctor, a salt warning, and a cook who takes medical advice far too literally. `main.py` writes the line to `/output/entry.txt`.

> My doctor told me to cut back on salt, so now I just cry directly into the pasta and let nature take its course.

## How it works

`main.py` holds the single line as a constant, asserts it is 1–200 characters of non-whitespace UTF-8 text (the bounty gate), creates `/output` if needed, and writes the line — and only the line — to `/output/entry.txt`. No title, no setup, no explanation around it.

### Run it

```sh
python3 main.py
```
